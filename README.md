# DawnMark

macOS 14+ 原生 Markdown 编辑器。编辑区使用 AppKit / NSTextView；设置、关于、工作区及购买界面使用 SwiftUI。不使用 WebView、HTML 渲染或 JavaScript。

## 工程结构

工作区的 `dawnmark` 和 `appcommerce` 是同级仓库，代码直接位于各自根目录，没有额外嵌套目录。以下运行命令在 `dawnmark` 仓库根目录执行。

```text
dawnmark/
  DawnMark.xcodeproj/           macOS App 工程，共享 DawnMark scheme
  Package.swift                应用与编辑模块的 Swift Package
  Sources/
    DawnMark/                  窗口、菜单、文档生命周期、外围界面
    DawnMarkSupport/           15 种语言的完整界面资源
    DocumentWorkspace/         文档目录、图片验证及安全复制
    MarkdownEngine/            AST 渲染、源码映射、编辑事务、撤销
    EditorKit/                 AppKit 源码与所见即所得编辑器
  Tests/                       编辑、存储、本地化回归测试
  Configuration/               Info.plist、沙盒权限、StoreKit 本地配置
  Scripts/                     工程生成与本地 .app 打包
appcommerce/
  Sources/CommerceCore/        试用状态、纯策略、可注入购买源与时钟
  Sources/CommerceStoreKit/    StoreKit 2 已验证交易、购买与恢复
  Sources/CommerceUI/          可选 SwiftUI 状态组件
  Tests/                      试用、恢复、撤销、失败及本地化测试
```

## 运行

打开 `DawnMark.xcodeproj`，选择 DawnMark scheme 并运行。共享 scheme 已绑定本地 StoreKit 配置，可测试免费试用和一次性买断；这些交易不会实际扣款。

命令行测试：

```sh
swift test
swift test --package-path ../appcommerce
swift run DawnMark --smoke-test
```

`--smoke-test` 仅 Debug 可用，验证真实窗口、8 个菜单、模式切换及只读，不模拟解锁；成功后自动退出，在系统临时目录生成 DawnMark-smoke.png。

构建独立本地应用：

```sh
./Scripts/build-app.sh
open build/DawnMark.app
```

该脚本需要完整 Xcode 和 XcodeGen，自动重新生成工程，通过 Xcode 构建 Release 沙盒版并进行本机临时签名，核验签名与沙盒、用户选择文件读写、书签权限后，替换 build/DawnMark.app，不保留旧包。构建开始和替换前都会检查 DawnMark 是否仍在运行；请先退出所有实例，避免覆盖运行中的程序。

该脚本生成带 App Sandbox 权限的本机临时签名应用，不是 App Store 发布包；正式上架仍需开发团队和发布签名。脚本不会自动启用 Xcode scheme 的 StoreKit 测试环境。未找到有效交易时只能阅读；测试编辑和新建文档请通过 Xcode 领取本地试用。不提供生产授权绕过开关。

修改 `project.yml` 后，通过 `./Scripts/generate-project.sh` 重新生成工程（需要 XcodeGen）。

## 编辑与文件

源码和所见即所得两种模式单区域切换，没有双栏。两种模式共享 Markdown 原文、选区映射和撤销；富文本操作生成局部源码补丁，不重新序列化全文。

### Markdown 兼容性

解析使用 swift-markdown / cmark-GFM，遵循 CommonMark 基础语法以及 GFM 表格、任务列表和删除线。
不启用 DocC 指令、符号链接或智能标点转换，不定义 DawnMark 私有文档语法。
直引号、连字符和省略号保持源码原文。普通正文编辑使用标准 Markdown 反斜杠转义保留字面标点；
输入与复制保留真实空格和 Tab，不自动替换成字符实体或插入零宽字符。行首缩进按标准规则解析，
例如独立段落前的四个空格可以形成缩进代码块；源码模式可以直接编辑原始语法。

有序列表按标准从首项编号递增显示，后续源码标记不会重新设定显示编号。例如 `1. a`、`1. b`、
`9. c` 显示为 1、2、3，但读取、渲染和保存不会自动改写这些源码数字。多个空行不一定结束列表；
标准解析器可能把它们解析为同一个松散列表。可视化编辑保留可映射的源码块间空行，不自行压缩；
其他编辑器的预览会按自身样式展示松散列表，不保证空白像素或行数与源码一一对应。

代码缩进、Tab 与行内代码行尾按标准解析内容展示，原始源码不因此改写。表格列对齐来自 GFM
分隔行中的冒号。格式命令生成标准标记，链接标签正确转义方括号；强调不把首尾空白包在标记内，
无法形成有效链接或强调节点的选区不会写入无效标记。自动回归使用独立的 Markdown AST 解析
检查生成结果，而非只比较本应用的显示字符串。

兼容性指支持相同 CommonMark/GFM 语法的编辑器能解析文档结构，不表示所有 Markdown 方言或
预览样式完全一致。原始 HTML、数学公式和 Mermaid 不在原生预览执行，源码仍保留；含相对图片
的文档需要连同图片目录复制。保存、另存为和内部复制不使用私有语法持久化格式。

左侧“大纲”从 Markdown AST 提取标题，以可折叠树形结构显示；跳级标题挂在最近的较高级标题下。点击标题可在两种模式下跳转，阅读权限也可使用。大纲随编辑更新，保留折叠状态并标示当前章节；没有标题时自动隐藏，编辑区恢复全宽。支持 ATX、Setext 和引用中的标题，不把代码块内容识别为标题；长标题悬停可查看全文。

拖动大纲与正文之间的分隔线可以调整大纲宽度，当前窗口保留调整值。大纲最小宽度 120 pt、最大 480 pt，并为正文保留至少 180 pt；窗口临时缩窄或大纲隐藏后重新显示，不重置用户选择的宽度。

文件菜单支持新建、打开、最近文档、保存、另存为及 Finder 定位；格式菜单按标题、行内、列表、段落、表格分类，支持状态勾选及不可用项校验。插入菜单支持链接、图片、表格、代码块和分隔线。

编辑菜单及 Command-C / Command-X / Command-V 支持复制、剪切与粘贴：源码模式复制所选 Markdown 原文；所见即所得模式同时复制可见文字和 DawnMark 专用 Markdown 格式数据，在本应用的所见即所得模式中粘贴时保留标题、行内格式、链接及完整列表、表格、代码块。部分选中粗体等文字时补齐格式标记；图片附件选区暂不导出专用格式数据，避免跨文档的相对路径失效。外部纯文本、RTF 剪贴板按纯文字粘贴，不导入外部字体或排版；源码模式不使用专用格式数据。支持中文、表情和多行文本，选区替换可撤销；只读文档仍允许复制、不允许剪切粘贴；图片剪贴板继续走图片导入流程。

新建时输入名称并选择父目录，创建 `名称/名称.md`。首次导入图片才创建 `images`，生成随机 UUID 文件名，并插入 `![](images/随机名.png)`。复制整个目录后，相对图片引用仍可使用。

图片显示宽度填满正文可用区域（保留编辑器内边距），高度按原比例调整，小图也会等比放大；调整窗口或拖动大纲分隔线时同步更新。表格内图片适配单元格宽度；未加载图片保持小占位符。布局不改变原图片文件或 Markdown 引用。

粘贴和拖放共用导入逻辑，拖放使用实际落点；异步导入追踪插入位置，修改目标选区时明确取消。文件图片保留受支持的格式，TIFF 转 PNG。数据限 50 MiB、单帧与累计像素限一亿；图片先完整落盘，再插入引用。撤销引用不立即删除图片，避免破坏重做。

另存为安全收集目录内的图片，支持引用式图片和去重，重写副本引用。越界或符号链接资源不未经授权读取。网络图片不自动请求，包含网络或目录外引用的自包含复制会被拒绝；需先显式下载／导入并更新引用。

Xcode 的 Debug 和 Release 均启用 App Sandbox、用户选择文件读写以及 app-scoped bookmark 权限。打开文档前恢复已保存的文件和目录授权；有本地关联图片但缺少目录权限时，通过系统面板请求授权文档所在目录。授权书签持久保存，重启后恢复，过期时更新；目录移动后按恢复的位置查找文档和相对图片。只授予文件权限不会自动授予整个目录权限，取消目录授权仍可阅读文档，但相关图片可能无法加载。

安全作用域在文档使用期间保持有效，关闭文档时释放。正常保存使用 NSDocument 生命周期及原子文件替换；关闭时可保存到期前已经接受的修改。构建脚本会生成带沙盒权限的签名包，完整系统授权流程仍需交互验收，正式上架前应使用开发团队签名构建验证。

## 试用与购买

应用免费下载；免费非消耗型 `15-day Trial` 交易确定试用起点，试用连续 15 × 24 小时；付费非消耗型永久商品一次解锁。恢复交易不重置试用，已退款／撤销的购买不授权。

启动窗口不等待商品查询或强制同步。后台读取 StoreKit 已验证权益并监听更新；商品价格只在购买界面加载，`AppStore.sync()` 只在用户点击恢复时执行。试用前展示买断价格和到期限制，价格失败可重试。

正式上架需自行配置开发团队、App Store Connect 商品、协议及定价。当前商品 ID 为 `com.liaolinrong.DawnMark.trial15days` 与 `com.liaolinrong.DawnMark.lifetime`；买断目标价格为 10 美元，本地美国测试商店已设置为 USD 10.00，正式价格仍需在 App Store Connect 单独配置。应用始终显示 StoreKit 返回的本地化价格。配置细节见 `Configuration/BUILDING.md`，公共库接口见 `../appcommerce/README.md`。

界面支持 15 种语言：英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、巴西葡萄牙语、葡萄牙葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、印度尼西亚语。在菜单“DawnMark → 设置 → 语言”中以各语言本名选择。

首次运行默认跟随系统，按系统首选语言列表匹配支持的语言，全部不支持时回退英语；用户手动选择的语言优先，繁简中文与葡萄牙语地区分别匹配。缺失翻译键不回退英文，而由完整性测试拦截。

在应用内切换语言会立即更新 DawnMark 自己的菜单和界面，同时只在本应用偏好域设置 `AppleLanguages`。macOS 自动添加的菜单和系统面板通常需要退出并重新打开应用后使用新语言，切换时会提示，不会强制退出。选择“跟随系统”会删除本应用的语言覆盖值，不修改全局语言或其他应用的设置；系统界面的实际语言效果需在目标 macOS 版本验证。

后续每个新增或修改的用户可见功能，必须同步覆盖上述全部 15 种语言，包括 DawnMark、AppCommerce 的内置界面和商品说明；逐语言校验键完整性、插值顺序和非空值。当前译文仍建议上架前进行母语审核。App Store 页面需在 App Store Connect 另外维护。

纯离线无法彻底防止系统时间篡改，也无法即时发现远程退款；不使用不可信的 UserDefaults 购买标记。

## 当前边界

- GFM 常见语法、任务复选框、原生图片、表格单元格编辑和增删行列已实现。表格使用 AppKit 原生文本表格，每列按整列最宽内容测量；空间不足时保留短列所需宽度，压缩长列并在各单元格内自动换行，行高随内容增长。窗口缩放和编辑会重新分配列宽，不修改 Markdown 原文；复杂单元格内容与 GitHub 的排版仍可能有差异。
- 所见即所得模式使用 Tree-sitter 为显式标注的代码块着色，覆盖 36 种语言和格式：
  - 应用和 Web：Swift、Objective-C、C、C++、C#、Rust、Go、Java、Kotlin、Scala、Dart、Python、Ruby、PHP、JavaScript（含 JSX）、TypeScript、TSX、HTML、CSS。
  - 数据、脚本和硬件：SQL、R、Julia、MATLAB、Bash、PowerShell、Lua、Fish、Verilog、SystemVerilog、VHDL、Assembly (GNU)。
  - 配置和构建：JSON、YAML、TOML、Dockerfile、Makefile。
- 未标注、未知语言或超过 64 Ki 个 UTF-16 代码单元的代码块仍等宽显示。源码模式仍显示 Markdown 原文；不执行 HTML、数学公式或 Mermaid。
- 高亮在后台运行，复用未变代码块的结果和修改前的语法树。高亮查询与第三方许可证随 EditorKit 打包。更新 SwiftPM 语法后，运行 `sh Scripts/update-highlight-resources.sh` 同步资源（可传入自定义的 `checkouts` 路径）；更新本地语法的锁定提交后，运行 `sh Scripts/update-highlight-resources.sh --refresh-vendored` 同步生成的 C 源码、查询和许可证。最后运行 `swift test --filter CodeHighlightTests`。
- 通过「插入 → 代码块…」指定新代码块的语言。在所见即所得模式，也可以使用当前代码块上方靠右的输入框，或右键使用「代码块语言…」。输入前缀会显示匹配建议，例如输入 `g` 后点击 `go` 即确认；直接键入自定义标签时按回车确认。未支持的标签会原样保留，仅不在 DawnMark 中高亮。标签修改可撤销，不改代码正文。
- 某些不能安全映射的富文本编辑会被拒绝；源码模式始终保留原始内容供精确编辑。
- 后台 AST 解析会合并连续输入并丢弃过期结果，但源码变化后仍可能全量更新文本布局；没有声称已实现增量解析或完成 Instruments 性能验收。
- 目录外图片需要显式导入；尚无孤立图片清理、外部编辑冲突合并或远程图片下载管理界面。
- 自动测试覆盖逻辑和原生编辑事件；真实 App Store 支付、退款与完整沙盒授权，需要签名后的 Xcode / Sandbox 验证。
